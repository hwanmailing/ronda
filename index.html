A FEW THINGS TO KNOW

궁금한 점을
먼저 확인하세요.

개발을 몰라도 만들 수 있나요?+

네. 템플릿을 선택하고 편집 화면에서 문구와 이미지 주소를 변경할 수 있습니다. 미리보기를 확인한 뒤 저장하세요.

GitHub 계정은 왜 필요한가요?+

완성된 사이트의 파일을 본인 GitHub 저장소에 보관하고 GitHub Pages로 호스팅하기 위해 필요합니다. 공개 배포 시 사이트 파일도 공개 저장소에 저장됩니다.

결제하면 바로 공개되나요?+

서버에서 결제 승인을 확인한 뒤 배포를 시작합니다. GitHub Pages 빌드가 끝나면 내 사이트 화면에서 공개 주소를 확인할 수 있습니다. 실패한 배포는 추가 결제 없이 다시 시도할 수 있습니다.

템플릿의 예약·쇼핑 기능도 포함되나요?+

템플릿의 상품과 예약 화면은 디자인 예시입니다. 실제 상품 결제나 예약 관리 시스템은 별도 연동이 필요하며, 문의는 설정한 이메일로 연결할 수 있습니다.

사이트를 나중에 수정할 수 있나요?+

네. 내 사이트에서 저장한 내용을 불러와 수정하고 다시 배포할 수 있습니다. 수정 전 미리보기로 내용을 확인하세요.
